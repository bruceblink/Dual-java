# Dual 本轮开发计划

## 审查结论

- 当前本地验证结果：`.\gradlew.bat test` 通过，`.\gradlew.bat build --warning-mode all` 通过。
- 项目主线是 Java 21 + Processing 客户端，另有纯 Java Relay Server 子项目。
- 本轮最需要优先处理的是联机对战的确定性和可恢复性，其次是构建配置可移植性与测试覆盖。

## 开发计划

1. 联机视角一致性修复
   - 问题：双方客户端都以“本地玩家在下方”的视角运行，远端方向键必须按 180 度视角进行上下/左右镜像。
   - 交付：远端玩家输入在 `NetworkPlayerEngine` 层统一镜像，移动和长弓瞄准保持两端一致。
   - 验收：新增单元测试覆盖远端方向镜像和冲突方向抵消。

2. 联机连接输入与错误提示
   - 问题：加入房间时端口非法会静默回退到默认端口，主机字段长度限制也只适合 IPv4。
   - 交付：加入界面支持 IP/域名主机名；端口必须在 1 到 65535 之间；错误直接显示在加入界面。
   - 验收：新增单元测试覆盖端口边界和非法端口。

3. Relay Server 稳定性修复
   - 问题：Relay 房间等待 ACK 时没有读超时；一侧异常断开时另一侧可能无法及时收到断线通知。
   - 交付：握手阶段设置超时；任一 relay 方向结束时关闭房间并尽量通知对端。
   - 验收：新增服务端单元测试覆盖握手超时关闭和断线转发。

4. 构建与依赖清理
   - 问题：根项目声明了未使用的 Guava 依赖；`gradle.properties` 绑定本机 JDK 绝对路径且重复声明 `org.gradle.jvmargs`。
   - 交付：移除未使用依赖；改用当前 JDK 21+ 编译 Java 21 目标；合并 JVM 参数。
   - 验收：完整 `build` 通过，README 与实际配置一致。

## 完成标准

- 所有计划项对应代码、测试和文档均完成。
- `.\gradlew.bat test` 通过。
- `.\gradlew.bat build --warning-mode all` 通过。
