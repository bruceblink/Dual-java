# Audio Sources

`Dual` currently ships no recorded or third-party audio files.

The charge-ready cue is generated at runtime by `SoundFeedback` as an 8-bit mono PCM tone:

- Frequency: 880 Hz
- Duration: 80 ms
- Sample rate: 44,100 Hz
- Amplitude: controlled by the in-game volume setting

Because the cue is generated from the implementation itself, there is no external asset license or attribution requirement for this release candidate. Any future recorded or synthesized asset must be added here with its license and source.
